# Truck Admin

Admin service for adding truck parking points on Google Maps.

## Stack

- React
- Vite
- Tailwind CSS
- Google Maps via `@vis.gl/react-google-maps`
- Lucide React icons

## Getting started

```bash
npm install
copy .env.example .env
npm run dev
```

Set `VITE_GOOGLE_MAPS_API_KEY` in `.env` before using the map.

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run preview
```
